# Contributing to Chess Win Analyzer

First off, thank you for considering contributing to Chess Win Analyzer! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub with:
- A clear and descriptive title.
- Steps to reproduce the bug.
- Expected behavior vs actual behavior.
- Browser and OS version.

### Suggesting Enhancements
We are always looking for ways to make the analysis better! If you have an idea, create an issue and label it as an `enhancement`. Include:
- Why this feature would be useful.
- A mockup or description of how it should work.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`npm run build`).
4. Issue that pull request!

## Local Development Setup
1. Clone your fork: `git clone https://github.com/YOUR_USERNAME/chess-win-analyzer.git`
2. Navigate to the directory: `cd chess-win-analyzer`
3. Install dependencies: `npm install`
4. Start the server: `npm run dev`

## Code of Conduct
Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
